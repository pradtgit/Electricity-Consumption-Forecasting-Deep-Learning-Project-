## Brief Summary of the Project

This project focuses on time series forecasting for hourly electricity consumption using the PJM dataset. The goal is to predict future PJME_MW values from historical Datetime and load data so that power operators can better plan generation, reserves and pricing. Since the PJM load series shows strong autocorrelation along with clear daily and weekly seasonality, longer term trends, holiday effects and occasional shocks, sequence aware deep learning models are well suited for this task. Building on insights from recent research, I will implement and test multiple architectures from scratch such as LSTMs, Transformers and other promising models identified in the literature and evaluate them using standard forecasting metrics like MAE, RMSE and MAPE. The final objective is to compare these approaches fairly and determine which deep learning model performs best for PJM electricity demand forecasting.
